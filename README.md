## 📋 Descripción

Sistema digital para gestionar la recaudación de pagos en ruta, permitiendo registro en tiempo real desde el camión hasta el cuadre en oficina.

### ✨ Características principales

- **Registro en tiempo real**: Los choferes registran pagos al instante desde sus celulares
- **Funciona sin conexión**: Guarda pagos localmente y sincroniza automáticamente
- **Panel de control**: Supervisión en vivo para el equipo de finanzas
- **Ahorro de tiempo**: Reduce el tiempo de cuadre diario en un 75%
- **Exportación Excel**: Descarga datos listos para conciliar

### 📊 Impacto estimado

- **1.000 facturas** procesadas digitalmente cada día
- **4 horas diarias** ahorradas en cuadre manual
- **~88 horas al mes** liberadas para el equipo de finanzas
- **100% trazabilidad** de todos los pagos

## 🛠️ Tecnología

- HTML5 + CSS3 + JavaScript vanilla
- Diseño responsive (móvil, tablet, desktop)
- Animaciones con Intersection Observer
- Carrusel interactivo
- Sin dependencias externas (excepto fuentes Google)

## 📱 Componentes del sistema

### App para Choferes
- Interfaz simple con botones grandes
- Registro de factura, monto, titular y medio de pago
- Funciona offline
- PWA instalable

### Panel de Oficina
- Dashboard en tiempo real
- Filtros por chofer, fecha, medio de pago
- Cierre de caja digital
- Exportación a Excel

## 🚀 Cómo usar

### Ver localmente

1. Descarga o clona el repositorio
2. Abre `index.html` en tu navegador
3. Navega usando scroll o los botones

### Publicar en GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a Settings → Pages
3. Selecciona la rama `main` y carpeta `/ (root)`
4. Guarda y espera unos minutos
5. Tu presentación estará en: `https://tuusuario.github.io/nombre-repo/`
